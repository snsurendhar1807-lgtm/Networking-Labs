DHCP Network Lab

Overview

A basic DHCP network simulation created using Cisco Packet Tracer to understand automatic IP address assignment.

Objective

- Configure a DHCP server.
- Automatically assign IP addresses to client devices.
- Connect multiple clients through a switch.
- Verify network connectivity.

Devices Used

- 1 Server
- 1 Cisco 2960 Switch
- 3 PCs

Concepts Practiced

- DHCP
- IP Address Assignment
- Client-Server Communication
- Switch Connectivity
- Network Verification

Tool Used

- Cisco Packet Tracer

Learning Outcome

Gained hands-on experience with DHCP and understood how a DHCP server automatically provides network configuration to client devices, reducing the need for manual IP configuration.
