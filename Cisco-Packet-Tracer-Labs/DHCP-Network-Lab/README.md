# DHCP Network Lab

A basic DHCP network simulation created using Cisco Packet Tracer to demonstrate automatic IP address assignment and client-server communication.

---

##  Objectives
* Configure a dedicated DHCP server.
* Automatically assign IP addresses and network parameters to client devices.
* Interconnect client devices using a layer 2 switch.
* Verify dynamic IP distribution and overall network connectivity.

---

##  Tech Stack & Tools
* **Simulation Tool:** Cisco Packet Tracer

---

##  Topology & Hardware
| Device | Quantity | Model / Type |
| :--- | :--- | :--- |
| **DHCP Server** | 1 | Server-PT |
| **Switch** | 1 | Cisco Catalyst 2960 |
| **Client PCs** | 3 | Generic PC |

---

##  Concepts Practiced
* **DHCP (Dynamic Host Configuration Protocol):** Understanding the DORA process (Discover, Offer, Request, Acknowledge).
* **IP Addressing:** Static server setup vs. dynamic host address allocation.
* **Client-Server Architecture:** Centralizing network management services.
* **Switch Connectivity:** Star topology layout and Ethernet port negotiations.

---

##  Learning Outcomes
Gained hands-on experience configuring a DHCP server to automate client network settings. Understood how automated IP assignment simplifies network administration and eliminates manual IP address conflicts across connected hosts.
