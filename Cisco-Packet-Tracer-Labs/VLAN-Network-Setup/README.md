# VLAN Network Setup

## Overview
This project demonstrates the implementation of Virtual Local Area Networks (VLANs) using Cisco Packet Tracer. The network is segmented into two departments—HR and Sales—to improve network organization, security, and broadcast management.

## Objective
- Create multiple VLANs on a Cisco switch.
- Assign end devices to their respective VLANs.
- Understand logical network segmentation.
- Practice VLAN configuration using Cisco CLI.

## VLAN Configuration
| VLAN ID | Department |
|---------:|------------|
| 10 | HR |
| 20 | Sales |

## Network Topology
- 1 Cisco 2960 Switch
- 6 End Devices (PCs/Laptops)
- VLAN 10 – HR
- VLAN 20 – Sales

## Concepts Practiced
- VLAN Creation
- Port Assignment
- Network Segmentation
- Switch Configuration
- Basic VLAN Management

## Tools Used
- Cisco Packet Tracer

## Files Included
- `VLAN-Network-Setup.pkt`
- Network topology screenshot
- Configuration screenshots (CLI)

## Learning Outcome
Successfully configured multiple VLANs on a Cisco switch and understood how VLANs logically separate devices within the same physical network, improving security and network management.
