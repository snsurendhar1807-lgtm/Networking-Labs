Hub-Based LAN Topology

A Cisco Packet Tracer project demonstrating the implementation of a hub-based LAN.

Features

- Star topology using a hub
- IPv4 address configuration
- Connectivity testing using Ping
- Packet flow analysis in Simulation Mode
- Comparison of hub and switch communication

Tools

- Cisco Packet Tracer

Key Learning

Understood hub broadcasting behavior, basic LAN communication, IP addressing, and the differences between hub- and switch-based networks.
