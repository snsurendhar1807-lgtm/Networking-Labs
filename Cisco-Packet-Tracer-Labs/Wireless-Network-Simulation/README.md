# Wireless Network Simulation

## Overview
A basic wireless network simulation created using Cisco Packet Tracer to understand wireless connectivity through an access point.

## Objective
- Configure a basic wireless network.
- Connect multiple end devices through an access point.
- Observe packet transmission using Simulation Mode.
- Verify wireless network connectivity.

## Devices Used
- Wireless Access Point
- PCs
- Laptop
- Smart phone

## Concepts Practiced
- Wireless Networking
- Access Point Configuration
- Wireless Client Connectivity
- Packet Flow Analysis
- Network Troubleshooting

## Tool Used
- Cisco Packet Tracer
